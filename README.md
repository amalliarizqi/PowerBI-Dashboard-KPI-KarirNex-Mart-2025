# Power BI Dashboard KPI KarirNex Mart 2025

## Deskripsi Proyek

Proyek ini merupakan pembuatan dashboard interaktif menggunakan **Microsoft Power BI** untuk menganalisis Key Performance Indicators (KPI) KarirNex Mart selama tahun 2025.

Dashboard dirancang untuk menyajikan informasi performa bisnis melalui visualisasi data dan indikator kinerja utama. Proyek ini mencakup pengolahan data, pembuatan measure menggunakan DAX, serta penyusunan visualisasi interaktif untuk membantu memahami performa bisnis.

## Tools

- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Microsoft Excel

## Dataset

Dataset yang digunakan merupakan data KarirNex Mart tahun 2025 yang diolah untuk menghasilkan indikator kinerja dan visualisasi guna mendukung pemantauan performa bisnis.

## Key Insights

Berdasarkan hasil analisis dashboard, diperoleh beberapa temuan utama sebagai berikut:

1. **Revenue:** Total pendapatan selama tahun 2025 mencapai **Rp773,03 Juta**.
2. **Revenue Achievement:** Pencapaian target revenue mencapai **99,88%**.
3. **Success Rate:** Tingkat keberhasilan transaksi mencapai **85,5%**.
4. **Average Rating:** Rata-rata rating pelanggan mencapai **4,03/5**.

## Dashboard Analysis

### 1. Key Performance Indicators (KPI)

Dashboard menampilkan empat indikator utama untuk memantau performa KarirNex Mart selama tahun 2025:

- **Revenue:** Total pendapatan yang diperoleh dari aktivitas penjualan.
- **Revenue Achievement:** Persentase pencapaian target pendapatan.
- **Success Rate:** Persentase keberhasilan transaksi.
- **Average Rating:** Rata-rata penilaian pelanggan terhadap produk atau layanan.

### 2. Performance Analysis

Menyajikan informasi mengenai performa bisnis berdasarkan indikator yang digunakan dalam dashboard.

### 3. Trend Analysis

Menganalisis perubahan performa berdasarkan periode waktu untuk mengidentifikasi pola dan tren data.

### 4. Category Analysis

Membandingkan performa berdasarkan kategori yang tersedia untuk mengetahui kontribusi masing-masing kategori terhadap keseluruhan performa bisnis.

## Dashboard Features

Dashboard dilengkapi dengan fitur interaktif yang memungkinkan pengguna untuk:

- Memantau empat indikator kinerja utama.
- Mengeksplorasi data melalui visualisasi.
- Melakukan analisis berdasarkan kategori dan periode.
- Menggunakan filter untuk melihat informasi sesuai kebutuhan.
